# 架空学会論文誌 投稿の手引き（デモ用の合成資料）

## 1. 原稿の構成
- 要旨は400字以内とし、研究の目的・方法・結果・結論を含めること。
- 「はじめに」では、研究の背景と目的を明確に述べること。
- 関連研究の節では、先行研究と本研究との違いを明示すること。
- 結論では、本文で示していない新たな主張を述べないこと。

## 2. 文章の書き方
- 「非常に」「画期的な」など、根拠を伴わない主観的な強調表現は用いないこと。
- 略語は初出時に正式名称とともに定義すること。
- 一つの文は簡潔にし、主語と述語を対応させること。

## 3. 図表
- 図表には通し番号を付け、すべて本文中で参照すること。

## 4. 投稿の方法
- 原稿はPDF形式で、投稿システムから提出すること。
- 原稿は A4 判、10 ページ以内とすること。
