あなたは、論文の投稿規定・ライティングガイド・報告ガイドラインから、原稿を点検するためのルールを取り出す担当です。

入力は、ルール資料のテキストの一部です。[p.12] のような印は、その後の文が資料の12ページにあることを示します。

資料の中から、論文の原稿が守るべき書き方の決まりを、1つずつ独立したルールとして取り出してください。

各ルールの項目：

- target_section：ルールが当てはまる箇所。Abstract / Introduction / Methods / Results / Discussion / 全体 / 図表 / 引用 のどれか
- rule：ルールの内容。原稿を読んで守れているか判断できるよう、具体的に1文で書く（例：「要旨には目的・方法・結果・結論を含める」）。資料の言語で書く
- check_type：判定の方法
  - mechanical：次のどれかに当たる、文字列の照合で判定できるルール（checker も指定する）
    - abbreviation_definition：略語を初出時に定義する
    - figure_table_reference：図表を本文中で参照する
    - unit_consistency：単位の表記をそろえる
  - llm：原稿の文章を読んで判定するルール
  - advisory：原稿から判定できない手続き上の注意（投稿の方法、ファイル形式、倫理審査の書類の提出など）
- checker：check_type が mechanical のときだけ、上の3つのどれか。それ以外は null
- lang：ルールが対象とする原稿の言語。ja / en / both
- page：ルールが書かれていたページ（[p.N] の N）。分からなければ null
- field_tags：分野が限られるルールなら分野名（例：「医学」）。限られなければ空のリスト

規則：

- 資料に書かれていないルールを作らないでください
- 1つの文に複数の決まりがあれば、別々のルールに分けてください
- 字数・ページ数・書式（フォント、余白）など、文章の内容に関わらない決まりは advisory にしてください
- ルールが無い部分（目次、連絡先、資料の説明など）からは何も取り出さず、rules を空のリストにしてください
